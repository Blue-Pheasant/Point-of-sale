# T07 — Router: route params + verbs + middleware pipeline

- **Phase:** 1 · Core
- **Phụ thuộc:** T03
- **Status:** ✅ Done (2026-05-29) — verify PASS, `php -l`/PHPStan/PHPUnit xanh.

## Bối cảnh
`Core/Router.php` là map tĩnh `path → callback`, chỉ **GET/POST**, không hỗ trợ param động (toàn dùng `?id=`). Trong `resolve()` (L104-113), việc gán `controller->action` rồi thay `controller = new ...` phụ thuộc thứ tự thực thi, dễ vỡ. Render layout còn trùng với `Core/View.php`.

## Mục tiêu
1. **Route params** `/{id}`: compile sang regex, truyền giá trị vào action — `show(Request $r, string $id)`.
2. Hỗ trợ đủ **GET/POST/PUT/PATCH/DELETE** + method spoofing qua field `_method` cho form HTML.
3. **Middleware pipeline** gắn theo route/group (`->middleware(...)`), router chạy middleware **trước** action (không phụ thuộc constructor controller như hiện tại).
4. Sửa bug gán controller/action.
5. Trả **404** (không match path) và **405** (sai method) đúng.
6. Cập nhật `Core/Route.php` thêm `put/patch/delete`, group + middleware; giữ `get/post` cũ.
