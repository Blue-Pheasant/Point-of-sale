# T11 — View gom render + helper escape

- **Phase:** 1 · Core
- **Phụ thuộc:** T08, T10
- **Status:** ✅ Done (2026-05-29) — verify PASS, `php -l`/PHPStan/PHPUnit xanh.

## Bối cảnh
Logic render layout (`{{content}}`) **trùng** ở cả `Core/Router.php` (L125, `renderView`) lẫn `Core/View.php`. Các view in dữ liệu động chưa escape → nguy cơ **XSS** (≈50 file trong `views/`).

## Mục tiêu
1. Gom render về **một** chỗ (`Core/View.php`); `Router` delegate sang View.
2. Tạo `Core/helpers.php` với: `e()` (htmlspecialchars), `csrf_field()` (T10), `old()`, `url()`. Autoload qua composer `files`.
3. Áp `e()` cho mọi biến động khi in trong `views/` (thay cho việc sanitize input đã bỏ ở T08).

## Files
- `Core/View.php`, `Core/Router.php`, `Core/helpers.php` (mới), `composer.json` (autoload files), `views/`

## Done (acceptance)
- Render layout chỉ còn một đường.
- Dữ liệu user hiển thị được escape; thử nhập `<script>` không thực thi.
