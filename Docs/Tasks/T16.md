- **Phase:** 2 · Quality
- **Phụ thuộc:** T06

## Bối cảnh & Mục tiêu
1. ID đang sinh bằng `uniqid()` (không an toàn khi nhiều request đồng thời) ở nhiều nơi (`Models/Product.php`, `User.php`, `Order.php`, `Cart.php`, controllers...) → chuyển sang **UUID v4** (thêm `ramsey/uuid`, hoặc helper dựa `random_bytes`), tập trung trong `DBModel::save()` để models không tự sinh id rời rạc.
2. Type-hint thiếu/nhất quán: vd `public $display = ''` trong `Models/Order.php` → `public string $display`; rà các property/return thiếu type.
3. Naming method nhất quán (số ít/số nhiều: `getCartItem` vs `getCartItems`...).
