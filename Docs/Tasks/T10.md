# T10 — Middleware pipeline + CSRF + Session hardening

- **Phase:** 1 · Core
- **Phụ thuộc:** T07
- **Status:** ✅ Done (2026-05-29) — verify PASS, `php -l`/PHPStan/PHPUnit xanh.

## Bối cảnh
`Core/Middleware.php` hiện chạy trong constructor controller (`registerMiddleware`), không phải pipeline thật. `Core/Session.php` gọi `session_start()` không guard `session_status()` và **không** set cookie params an toàn. Chưa có **CSRF**. `Services/AuthService.php` lưu **user id trần** vào cookie `member_login` không có flag bảo mật.

## Mục tiêu
1. `Core/Middleware.php` → interface `handle(Request $req, Closure $next)`, chạy trong **router pipeline** (T07). Tái dùng logic `Middlewares/AuthMiddleware.php`, `AdminMiddleware.php`.
2. `Core/Session.php`: guard `session_start()` bằng `session_status()`; `session_set_cookie_params` (`httponly=true`, `samesite=Lax`, `secure` theo `APP_ENV`).
3. **CSRF**: sinh + verify token trong Session; thêm `Middlewares/CsrfMiddleware.php` gắn cho route POST/PUT/PATCH/DELETE web; helper `csrf_field()` (dùng ở T11).
4. Remember-me (`AuthService`): thay user id trần bằng **token ngẫu nhiên lưu DB**, cookie set kèm httponly/samesite/secure; auto-login đối chiếu token.

## Files
- `Core/Middleware.php`, `Core/Session.php`, `Middlewares/` (+ `CsrfMiddleware.php`), `Services/AuthService.php`

## Done (acceptance)
- Form POST thiếu CSRF token → bị từ chối.
- Cookie có HttpOnly/SameSite (+ Secure ở prod).
- Middleware chạy theo pipeline trước action.
