# T06 — DBModel trên Query Builder

- **Phase:** 1 · Core
- **Phụ thuộc:** T05
- **Status:** ✅ Done (2026-05-29) — verify PASS, `php -l`/PHPStan/PHPUnit xanh.

## Bối cảnh
`Core/DBModel.php`: `save()`/`update()`/`delete()` **luôn `return true`** bất kể `execute()` thành công hay không → không phản hồi lỗi. `findOne()` ghép điều kiện bằng `implode("AND", ...)` **thiếu khoảng trắng** → SQL sai khi có >1 điều kiện (`a = :aAND b = :b`).

## Mục tiêu
1. Cho `find / findAll / where / save / update / delete` dùng Query Builder (T05).
2. `save/update/delete` **trả kết quả thật** của `$statement->execute()`.
3. Sửa `findOne` (nối `" AND "` đúng, hoặc dùng builder).
4. Giữ chữ ký method công khai để Models/Services không phải đổi nhiều.
