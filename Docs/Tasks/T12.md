- **Phụ thuộc:** T04, T07

## Bối cảnh
`Core/Application.php` (`bootstrap`, L119) chỉ bắt `Exception` chung rồi render `_error`. Còn `die()`/`echo getMessage()` rải rác (vd `Core/Database.php`) làm **lộ thông tin**.

## Mục tiêu
1. Handler tập trung map exception → HTTP status + view:
   - `NotFoundException` → 404
   - `ForbiddenException` → 403
   - `ForLoginException` → redirect `/login`
   - còn lại → 500
2. Theo `APP_DEBUG`: dev hiện stack trace, prod hiện trang generic (không lộ chi tiết).
3. Thay mọi `die`/`echo getMessage` còn sót.
