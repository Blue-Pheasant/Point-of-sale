# T05 — Query Builder param-bound duy nhất *(fix gốc SQL injection)*

- **Phase:** 1 · Core
- **Phụ thuộc:** T04
- **Status:** ✅ Done (2026-05-29) — verify PASS, `php -l`/PHPStan/PHPUnit xanh.

## Bối cảnh
`Common/Query.php` build SQL bằng nối chuỗi giá trị: `get()` (L70), `insert()` (L98), `update()` (L118,124), `delete()` (L140) đều `"$key = '$value'"` → **SQL injection**. Nhiều service/model cũng nối chuỗi (`'%$keyword%'`, `WHERE id = '$id'`). Mặt khác `Query::prepare/getAll/getCount` đã bind param đúng chuẩn — đây là mẫu để chuẩn hoá.

## Mục tiêu
1. Tạo Query Builder fluent **luôn bind param**: `select / where / whereLike / orderBy / limit / offset / get / first / count / insert / update / delete`.
2. Builder sinh placeholder `:p0, :p1...` và thực thi qua `Query::getAll/prepare` (đã an toàn sẵn).
3. Đổi `Query::get/insert/update/delete` cũ thành wrapper `@deprecated` an toàn (param-bound) để code cũ không gãy.
4. Có unit test cho builder (sẽ mở rộng ở T17).
