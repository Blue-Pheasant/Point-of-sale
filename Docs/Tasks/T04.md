# T04 — Gom tầng kết nối DB

- **Phase:** 1 · Core
- **Phụ thuộc:** T03
- **Status:** ✅ Done (2026-05-29) — verify PASS, `php -l`/PHPStan/PHPUnit xanh.

## Bối cảnh
`Core/Database.php` có **2 đường kết nối** (singleton `getInstance()` trả PDO + constructor tạo `$this->pdo`) gây nhầm lẫn; `die($ex->getMessage())` (L62) và `echo ... getMessage()` (L86) **lộ thông tin DB**; `SET NAMES 'utf8'` (L60,84) lệch với collation thực tế `utf8mb4_vietnamese_ci`.

## Mục tiêu
1. Hợp nhất về **một** đường kết nối duy nhất.
2. Set PDO options: `ERRMODE_EXCEPTION`, `EMULATE_PREPARES => false`, `DEFAULT_FETCH_MODE => FETCH_ASSOC`.
3. Charset `utf8mb4`.
4. Lỗi kết nối → **ném exception** cho error handler (T12) xử lý; bỏ `die`/`echo`.
5. Giữ `getInstance()` và `->pdo` hoạt động (alias) để code cũ không gãy.
