## Bối cảnh
`.env` đang bị commit kèm **password thật** (`DB_PASSWORD=955363`). `docker-compose.yml` hardcode password yếu. Đây là điểm trừ bảo mật nặng nhất.

## Mục tiêu
1. Thêm `.env` (và cân nhắc `vendor/`) vào `.gitignore`.
2. Gỡ `.env` khỏi git: `git rm --cached .env` (giữ file local).
3. **Rotate** password DB (đổi mật khẩu mới).
4. `docker-compose.yml`: chuyển credential sang biến môi trường (`${MYSQL_PASSWORD}`...), không hardcode.
5. Thêm `APP_ENV` và `APP_DEBUG` vào `.env` và `.env.example` (dùng cho error handler T12 + cookie secure flag T10).

## Files
- `.gitignore`, `.env`, `.env.example`, `docker-compose.yml`

## Done (acceptance)

- `.env.example` có đủ key (DB_* + APP_ENV + APP_DEBUG), không chứa giá trị nhạy cảm.
- App vẫn chạy với `.env` local.
